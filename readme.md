# 🏛️ Qu-Easy: A Royal Quiz Experience

Qu-Easy is a sophisticated, web-based quiz application designed with a "Royal Library" aesthetic. It features deep charcoal gradients, elegant gold accents, and classic serif typography to provide a premium user experience while testing knowledge in Geography and History.

## 🌟 Features

* **Royal Aesthetic:** A custom-designed UI featuring deep emerald/charcoal backgrounds and metallic gold finishes.
* **Dynamic Questioning:** Quizzes are pulled from JSON data and randomized every time you play.
* **Interactive Feedback:** Real-time visual feedback for correct and incorrect answers with smooth CSS transitions.
* **Fully Responsive:** Designed to look majestic on desktops, tablets, and smartphones.
* **Score Tracking:** A dedicated "Hall of Fame" result screen to review your performance.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure for the quiz interface.
* **CSS3:** Custom "Glassmorphism" effects, Flexbox layouts, and Google Fonts integration (Cinzel & Playfair Display).
* **JavaScript (ES6+):** Fetch API for loading questions, DOM manipulation for the quiz logic, and randomization algorithms.
